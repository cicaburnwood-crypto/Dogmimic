## 任务定义

机器人从静止姿态出发，双脚离地一次，向 +x 方向跳跃，目标为双脚落点中心相对起点前移 0.6 米，并站稳。

参考使用 LAFAN1 G1 `jumps1_subject1.csv` 在 50Hz 数据中的 318–374 帧。取一次前跳，调整前向位移、足部摆动轨迹和下蹲高度，再用双腿逆运动学固定支撑脚，补入 0.5 秒初始静止、0.9 秒落地恢复和 1.2 秒结束站立。总长 3.72 秒。`reference.json` 记录生成参数；`reference.mp4` **仅展示参考动作，不是训练后的策略表现**。

生成后的脚部水平位移为 0.6 米，双脚离地高度峰值约 6.9 厘米，参考双脚超过 2.5 厘米的时长为 0.26 秒。支撑脚采用约 1 毫米接触深度。

训练沿用世界模型 + 想象轨迹的优化流程，在原跟踪奖励上提高根部位置精度，并加入全局脚部位置和脚部高度跟踪。训练重置中 25% 从动作首帧开始，其他位置按原来的回报采样；使用摩擦、姿态、关节和速度扰动。

## 成功判据

独立评估从动作首帧出发，所有初始速度为零；第 0 次为名义姿态，其他试验加入小幅初始姿态扰动。

同时满足以下条件才计为成功：

1. 完整执行，无摔倒终止。
2. 双脚脚底高于地面 2 厘米至少 0.08 秒。
3. 双脚落点中心向前位移 0.50–0.70 米，横向误差小于 0.10 米。
4. 起跳前任一脚的水平位移小于 0.08 米。离地边界用脚底 3 毫米阈值识别，双脚离地后至达到 2 厘米高度之间的空中前移不计入此项。
5. 落地到结束的脚部中心移动小于 0.10 米，最终前向位移仍在 0.50–0.70 米。
6. 最后 1 秒内根部水平速度小于 0.25m/s、倾角小于 25°、根部高度大于 0.5 米；膝、腕、躯干和骨盆不贴地。

距离使用实际仿真轨迹计算，参考动作本身的 0.6 米不作为策略成功的证据。

最终评估使用 `metric_version=2`：修正了初版将离地初期的空中移动计入“起跳前位移”的问题，并将双脚落地高度阈值从 15 毫米收紧至 3 毫米。训练中的历史 `jump_eval.jsonl` 保留初版结果。最终报告以 `final_test/evaluation.json` 为准。

复测中第 0 次不加扰动；其余试验在初始水平位置加入 ±3 毫米、关节角及根部欧拉角加入 ±0.008 弧度的扰动。初始速度全部为零，平地摩擦系数为 1.0，关闭观测噪声。成功率仅对应这些仿真条件。
