# G1：从随机参数学习前进、停止和再启动

任务使用 SuperMimic 的在线世界模型、多步动力学损失、想象轨迹反向传播和价值函数训练。任务奖励改为速度指令、平衡、站稳和动作正则；这是基于社区实现的无参考动作扩展，并非论文原始动作模仿基准。

- 不读取动作 NPZ，不创建 MotionLibrary，不使用教师、预训练策略或已有世界模型。
- 每次 reset 使用机器人资产的固定默认关节姿态，根高度 0.76 m；根线速度、角速度和关节速度全部为零。训练时只扰动关节角度和动力学参数。
- 指令为 `[前向速度, 横向速度, 偏航角速度]`。本实验训练前进与停止，后两项固定为零。
- 观测为关节角/速度、机身角速度、重力方向、上一动作、机身线速度，共 96 维；使用 5 帧历史。没有动作相位或未来参考姿态。
- 训练使用随机 2–5 秒指令段，30% 为零速度；每个 episode 起始先保持 0.4–1 秒零指令。训练指令上限逐步从 1 m/s 增至 3 m/s。
- 奖励基于物理状态：速度误差、偏航误差、直立/高度、零指令下残余运动、关节限位、动作平滑和脚滑。不指定步态轨迹。

## 独立验收

每次测试均从零速度开始，测试序列固定为：停止 0–1 秒、前进 1–5 秒、停止 5–8 秒、再次前进 8–12 秒、停止 12–16 秒。每个速度测试一组默认姿态及多组关节扰动。

成功必须同时满足：全程不摔倒；根高度大于 0.5 m；倾斜角小于 0.6 rad；两段前进末尾各 2 秒的平均前向速度误差不超过 `max(0.12 m/s, 20% × 指令速度)`；停止等待 2 秒后的平均平面速度低于 0.15 m/s、峰值低于 0.25 m/s、位移小于 0.2 m；横向偏移小于 0.7 m。一个速度通过需至少 90% 试验成功且默认姿态成功。

失败后即使环境自动 reset，也不会恢复该试验的成功资格；视频显示 ACTIVE 或 FAILED / RESET。训练奖励不能代替独立验收。

## 服务器与运行

服务器 `super_5090`，根目录 `/home/liudiwen/projects/supermimic_vibe`。GPU 4、5 训练，GPU 6 独立评估。其他用户占用的 GPU 0–3、7 不作修改。

正式运行目录：`runs/command_fresh_h32`；评估目录：`runs/command_fresh_h32_eval`。

```bash
.venv/bin/python experiments/command_locomotion/launch.py \
  --out runs/command_fresh_h32 --gpus 4,5 --cold-cache \
  --num-envs 2048 --wm-batch 1024 --pi-batch 2048 \
  --iterations 30000 --horizon 32 --ckpt-every 2000 \
  --log-every 200 --buffer-steps 500 --lr 0.0001 \
  --start-speed 1.0 --max-speed 3.0 --curriculum-steps 20000
```

全局并行环境 4096，世界模型批量 2048，想象轨迹批量 4096；每次更新拟合 4 批世界模型，再做 32 步想象策略优化和 2 轮价值函数拟合。学习率按双 GPU 的平方根缩放。

`launch.json` 保存参数、源代码哈希和启动时刻；`launch_timing.json` 保存进程完整墙钟耗时；每个 checkpoint 保存训练循环耗时、启动以来耗时与无参考动作元数据。正式运行采用空的编译缓存，计入初始化及编译时间。此前短训练只验证实现，权重没有用于正式训练。

`audit.py` 在禁止实例化动作库的条件下实际运行，并断言初速度严格为零。默认姿态配合固定零动作在 2 秒内会失稳，策略需要学习平衡；该基线结果不等同于训练后的表现。

尚未完成验收时，不应将训练已启动或奖励上升表述为“模型已学会启停”。
