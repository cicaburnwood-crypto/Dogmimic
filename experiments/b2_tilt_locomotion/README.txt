B2 倾斜姿态全向 locomotion v1 — SuperMimic vibe

任务与单位
命令为 [vx, vy, yaw_rate, roll, pitch]。内部弧度；x 前，y 左，z 上。
vx in [-4,4] m/s，vy in [-1,1] m/s，sqrt(vx²+vy²)<=4 m/s。
roll 与 pitch 分别在 [-20,20] 度，允许同时达到两个轴的边界；不把二者合成倾角再裁成20度。
速度在机身朝向对应的地面水平坐标系计算。yaw_rate 是 Euler heading 的导数，不是倾斜时的 IMU body-z gyro。
yaw 累计转角无上限，接口不裁剪 yaw_rate；有限训练域最高 +/-2 rad/s（约114.6度/秒），
平移时 yaw 采样上界 min(2,2/max(1,平面速度)) rad/s，避免把无限角速度或任意高速转弯宣称为目标。
这是训练采样范围，不是额外 UI 操作锁。4 m/s 时训练到 +/-0.5 rad/s；后续可按物理评测扩大。
任意小数角度、组合平移转向、方向反转、移动中改变倾角、停走及最后回正均在同一策略中。
命令平滑只作用于期望机身角度与速度，不修改关节目标，不复用旧站立插值控制器。

上游 train/networks/kinematics/rotations 等学习核心字节不变；新增任务适配层。
在线学习世界模型、k8 自回归、H32 BPTT、GAE critic、UTD=.4，不换成 PPO 或 NJU。
Actor/WM/critic 随机初始化，空 replay、新优化器，无官方策略、旧策略、IK 教师或动作数据。
这是命令条件新任务，不是原论文动作追踪基准的等价复现实验。

物理与奖励
MuJoCo 5ms，Actor 20ms，重力显式 [0,0,-9.81]；地面与脚同设摩擦 .4–1.3。
全机质量 .9–1.1、COM +/-1cm、PD倍率、编码器偏差、传感噪声、0–10ms动作延迟、非对称关节初姿。
本任务空载，不添加之前后腿站立的负载任务。
XML 200/200/300 Nm 每腿限幅、PD 250/8、物理关节范围不变。
奖励联合水平速度、Euler yaw rate、roll/pitch 误差、机身高度、垂直速度、支撑脚滑移、
摆腿抬脚、动作平滑、力矩需求、关节速度与功率。移除了原地任务中禁止平移/脚移动的奖励。
步态时钟借鉴已存档 MIT Walk These Ways 0e7236bdc81ce855cbe3d70345a7899452bdeb1c 的对角相位/高斯接触方式；
速度相关频率2–3.4Hz、支撑占比.65–.55，摆高.08m是本次B2适配，不能声称公开验证过此完整奖励配置。
不使用之前不可靠的接触力预测头；奖励几何接触与独立评测真实力传感分开。

训练
GPU6，1024环境、WM batch512、Actor batch1024；80000次/6小时有限预算，结束保存不自动重启。
课程依次 (.5m/s,5度,.35rad/s)、(1,10,.6)、(2,15,1)、(3,20,1.5)、(4,20,2)。
50%当前课程、30%低速复习、20%全域采样，自始覆盖4m/s与叠加20度；课程不改变最终验收范围。
两次独立物理评测当前课程每条件 >=87.5% 且名义通过后才扩展主采样课程。
每4000次 Actor-only MuJoCo，最终完整交叉矩阵；以实际跟踪结果为准，奖励与WM loss不是成功率。
不恢复定时任务，不修改现有机器人服务，不执行实机动作。

独立验收
固定文件 evaluation_manifest.json。每条件32次，名义通过并至少31/32。
每次从零速度起步，第一命令、反向命令、停止回正分段考核，不用平均值掩盖单段失败。
常规41条件；最终还包含 roll/pitch 九个边界组合与前后、侧向、斜向、转向组合，以及连续小数和摩擦边界。
每轴角跟踪及平移/yaw误差、停止漂移、真实支撑脚滑动、非脚接触、机身高度、关节限位、实际速度超限均检查。
每5ms记录峰值实际关节速度、机械功率。旧后腿站立6rad/s/1501W是旧任务实验预算，不作为新4m/s任务厂家额定；
本任务物理模型维持其原力矩限幅，真实电机速度/功率能力尚未辨识。仿真通过不等于可部署实机。
完整DEV及两组独立物理随机种子都通过才记录仿真任务accepted，hardware_validated始终为false。
