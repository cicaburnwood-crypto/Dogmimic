# G1 跳远鲁棒性 v2

依据 IMG_6782.MP4 和三次实机跳跃日志，针对蹬地时实机与仿真动态偏差增加随机化。只在 super_5090 仿真训练，不替换机器人当前模型。

- 策略初始化：本聊天自行训练的 jump_60cm 第 6000 次 checkpoint；不是从零训练。
- 世界模型/critic 随机初始化；新 replay、新优化器；前 1000 次仅训练世界模型，随后恢复 Actor/critic 更新。
- 保持 SuperMimic 训练器、原有动作跟踪奖励、原有 60 cm 距离/起跳/落地/站稳验收标准。
- 世界模型/critic 的特权环境参数从 33 扩至 42，新增质量、PD、力矩、延迟、左右摩擦差异和外力参数。Actor 输入仍为原本 930 维本体历史与 730 维参考目标，不接收这些特权参数。
- 75% 环境采样广泛随机化，25% 标称动力学条件复习（仍保留观测/起始姿态/COM 扰动）。摩擦基值 0.15–1.5、左右差异 ±30%（各脚限于 0.1–1.8）；地面不高于两脚系数，保证实际接触参数不被地面覆盖。摩擦模型仍为 MuJoCo 库仑模型，不声称包含所有地面材料。
- 质量与惯量统一 0.9–1.25 倍；Kp 0.8–1.2、Kd 0.7–1.3 倍；输出力矩上限 0.7–1.0 倍；执行延迟 0–40 ms、5 ms 分辨率。
- 躯干 COM、编码器偏置、观测噪声、初始姿态扰动。多数 reset 从动作开头开始，站立初始关节在参考姿态与实测原生站姿之间混合；起始零速度。非开头 reset 仍用于困难阶段学习。
- t=0.96–1.36 s 蹬地阶段施加水平每轴 ±25 N、垂直 ±10 N 外力。它是有界外力扰动，不等于真实吊绳/吊架碰撞模型。
- 每 1000 次发布评测候选，GPU6 独立运行 21 组 × 32 次 = 672 次物理测试。包含摩擦两端、左右不对称、原生站姿、质量、PD、输出能力、延迟、俯仰、外力与组合边界。
- 初始策略同样评测，保存 initial_eval.json；best.pt 只从训练后的候选中选择，先比较最差场景通过数，再总通过数与完成数，不依据训练奖励。评测使用独立随机种子，不能当作实机验证。
- GPU4/5 训练，每卡1024环境；GPU6评测；预算40000次、训练计时6小时。启动与编译、最终评测时间另计。结果未达标也会结束预算，不宣称收敛。

入口 launch.py；实际轮次及进程在 latest_launch.json。评测 worker 只处理最新候选，最终收到 DONE 后完成最后候选再写 EVAL_DONE.json。日志、评测逐例结果、模型、配置均留存在该轮 runs 目录。
